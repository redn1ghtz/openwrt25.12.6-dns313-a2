<a id="chapter-1"></a>
## 2. Что исправлено и проверено

- **RAM:** исправлен Device Tree для 32 МБ; отключено резервирование CMA (`cma=0`).
- **Ethernet:** исправлена инициализация Gemini Ethernet и очередей, заводской MAC-адрес читается из NOR flash через NVMEM. Основной порт работает на **1 Гбит/с**. Сообщение `PHY init failed` для второго PHY не препятствует работе сети.
- **USB:** исправлен pull-up контроллера FOTG210; работает USB gadget **CDC ACM**. В Windows NAS определяется как последовательный COM-порт, через PuTTY доступна интерактивная консоль OpenWrt (`/dev/ttyGS0`).
- **SATA и swap:** OpenWrt загружается с HDD, корень — ext4; предусмотрен swap-раздел 128 МБ.
- **Данные:** отдельный раздел ext4 для файлов, монтирование в `/mnt/sda1`.
- **SMB:** через `ksmbd` проверены копирование и удаление файлов из Windows (включено в сборку).
- **hd-idle:** включено в сборку программное обеспечение для настройки остановки диска при простое.
- **Питание:** проверено корректное завершение работы кнопкой питания с синхронизацией данных и остановкой диска.

## 4. Скачивание и запись образа на HDD

Клонируйте репозиторий:
```sh
git clone https://github.com/redn1ghtz/openwrt25.12.6-dns313-a2.git
cd openwrt25.12.6-dns313-a2
```

Контрольная сумма **SHA256:** `ce7dcd0346d4ffe7f27b130637cf7968ed987f4c79b19086c24c161c419716fb`

> **Внимание:** запись образа перезапишет таблицу разделов и часть содержимого выбранного диска. Сохраните важные данные. Не перепутайте HDD NAS с системным диском компьютера.

Подключите HDD к компьютеру с Linux и определите имя устройства:

```sh
lsblk -o NAME,PATH,SIZE,MODEL,SERIAL,TYPE,MOUNTPOINTS
```

Убедитесь, что разделы целевого диска не смонтированы. Распакуйте образ:

```sh
gunzip DNS-313-A2-OpenWrt-25.12.6-final.img.gz
```

Запишите образ, заменив `/dev/sdX` **на проверенное имя всего HDD**, а не отдельного раздела:

```sh
sudo dd if=DNS-313-A2-OpenWrt-25.12.6-final.img of=/dev/sdX
sync
```

После записи **на этом же компьютере** обновите таблицу разделов (при необходимости переподключите диск) и подготовьте swap-раздел. Здесь и далее замените `sdX` на имя HDD NAS:

```sh
sudo partprobe /dev/sdX
sudo mkswap /dev/sdX2
```

`mkswap` создаёт swap-сигнатуру. **`swapon` на компьютере выполнять не нужно:** это включило бы swap только для компьютера, а не для NAS.

Безопасно отключите HDD, установите его в NAS, подключите Ethernet и включите питание.

<a id="chapter-5"></a>
## 6. Разметка HDD

После записи образа:

| Раздел | Назначение | Размер |
|---|---|---|
| `/dev/sda1` | Данные, ext4 | Создаётся вручную из свободного пространства |
| `/dev/sda2` | Swap | 128 МБ |
| `/dev/sda3` | Загрузка, ext2 | ~16 МБ |
| `/dev/sda4` | Корень OpenWrt, ext4 | ~104 МБ |

**Не удаляйте разделы 2, 3 и 4 и не форматируйте разделы 3 и 4.** Swap на разделе 2 подготовлен на ПК сразу после записи образа. Раздел 1 в исходном образе отсутствует.

### Создание раздела данных

На NAS:

```sh
fdisk /dev/sda
```

Создайте раздел **номер 1** в свободной области диска (n, p ENTER, ENTER, ENTER, ENTER, w). Проверьте результат:

```sh
fdisk -l /dev/sda
```

Форматируйте **только новый раздел 1**:

```sh
mkfs.ext4 /dev/sda1
mkdir -p /mnt/sda1
```

### Настройка автомонтирования

Посмотрите UUID разделов:
```bash
block info
```

Откройте конфигурацию:
```bash
vi /etc/config/fstab
```

Добавьте запись для раздела данных, подставив его UUID:
```text
config mount
	option target '/mnt/sda1'
	option uuid 'REPLACE_UUID_SDA1'
	option enabled '1'
```

Убедитесь, что swap также включён:
```text
config swap
	option uuid 'UUID_РАЗДЕЛА_SDA2'
	option enabled '1'
```

Если запись swap уже существует, не создавайте вторую — измените существующую.

**Важно:** автоматическая генерация `fstab` через `block detect | uci import fstab` может создать запись swap с `enabled '0'`. Поэтому после изменения конфигурации обязательно проверяйте swap.

Перезагрузите NAS:
```bash
reboot
```

Проверьте монтирование и swap:

```sh
df -h /mnt/sda1
free -h
```

Swap должен иметь общий размер около 128 МБ. Если он не активировался, проверьте `/etc/config/fstab`; временно включить его на NAS можно командой `swapon /dev/sda2`.

## 7. Настройка SMB-сервера ksmbd

Создайте папку и назанчьте владельца:

```sh
mkdir -p /mnt/sda1/Data
chown nobody:nogroup /mnt/sda1/Data
chmod 0770 /mnt/sda1/Data
ls -ld /mnt/sda1/Data
```

Создаем пользователя ksmbd (потребуется ввести новый пароль):
```sh
ksmbd.adduser root
```

В настройках общего ресурса задайте (Services -> Network Shares):

| Параметр | Значение |
|---|---|
| Interface | `lan` |
| Name | `Data` |
| Path | `/mnt/sda1/Data` |
| Allowed users | `root` |

Save & Apply

В проводнике Windows откройте:

```text
\\IP_АДРЕС_NAS\Data
```

Проверены копирование и удаление файлов. Сообщение `ksmbd: parse_dacl: Error -22 mapping Owner SID to uid` связано с отображением Windows SID на Linux UID; обычные операции с файлами в тестах работали. Полная совместимость Windows ACL не проверялась.

**Не открывайте SMB-порт 445 в интернет.**

<a id="chapter-7"></a>
## 8. Установка и настройка остановки HDD при простое (hd-idle)

Зайдите в веб-интерфейс OpenWrt и перейдите в Services -> HDD Idle -> Edit:

| Параметр | Значение |
|---|---|
| Enable | `YES` |
| Disk | `/dev/sda` |
| Idle time | `15` |
| Idle time unit | `minutes` |

Save -> Save & Apply

Эти параметры задают 15 минут до отключения диска при простое.

<a id="chapter-8"></a>
## 9. USB-консоль (Windows)

1. Подключите NAS к компьютеру USB-кабелем.
2. В диспетчере устройств Windows найдите «Устройство с последовательным интерфейсом USB (COMx)».
3. В PuTTY выберите **Serial**, укажите соответствующий COM-порт и скорость **115200**.
4. Откройте соединение — доступна консоль `root@OpenWrt:~#`.

В тестовой системе Windows использовался `COM8`; у вас номер может отличаться.

<a id="chapter-9"></a>
## 10. Особенности и ограничения

- Всего 32 МБ физической RAM; видимый системе объём меньше из-за резервирования памяти.
- Swap помогает при нехватке RAM, но медленнее оперативной памяти.
- ARMv4 300 МГц ограничивает скорость SMB и дополнительных служб.
- Возможны сообщения об отсутствующем втором Ethernet PHY.
- Работа на ревизиях, отличных от A2, не проверялась.
